Right Sidebar

Shell ComponentTheme Adaptive

A unified collapsible right navigation sidebar that supports all Harmony themes. The sidebar adapts its icons and sections based on the theme variant. All themes include the Dela logo (RS_DelaDefault.svg default, RS_Dela_Active.svg when active) as the first icon, followed by theme-specific navigation items organized into three sections.

Live Demo

Switch themes using the picker in the top header to see how the right sidebar adapts. The sidebar automatically shows the correct icons and sections based on the current theme. All themes start with the Dela logo (RS_DelaDefault.svg / RS_Dela_Active.svg).

Behavior

Collapsible

Collapsed by default showing only icons (~52px width). Expands on hover to reveal labels (~220px width).

Fixed Position

Docked to the right edge of the viewport, vertically centered. Stays in place while content scrolls.

Three Sections

All themes organize items into three sections. CP theme has different items per section compared to VP/PPM/Maconomy themes.

Dela AI Integration

All themes feature the Dela logo (RS_DelaDefault.svg / RS_Dela_Active.svg) as the first icon, providing consistent access to AI assistance across all themes.

Theme Variants

CPCostpoint Theme

3 Sections:

  • AI & Quick Actions (Dela AI, Notifications, Files)
  • Document Actions (Print, Layout Options)
  • Settings & Help (Microphone, Offline, Keyboard Shortcuts, Help)

PPMPPM Theme

3 Sections:

  • Actions (Dela AI, Edit, Search, Actions, Related, Templates, Upload, Download)
  • Notifications & Help (Notifications, Help, Share)
  • Settings (Accessibility, Language, Dark Mode)

3 Sections:

  • Same structure as PPM theme
  • All themes start with Dela logo (RS_DelaDefault.svg / RS_Dela_Active.svg)

MaconomyMaconomy Theme

  • Same structure as PPM theme
  • All themes start with Dela logo (RS_DelaDefault.svg / RS_Dela_Active.svg)

Styling

Visual Properties

  • Background: Uses theme-specific --nav-bg design token
  • Border: Uses theme-specific --border-color design token
  • Border Radius: 12px (top-left and bottom-left only)
  • Shadow: Multi-layered elevation shadow (theme-aware)
  • Icon Color: Uses theme-specific --text-primary design token
  • Hover Background: Uses theme-specific --hover-bg design token
  • Layout: Right-aligned (labels on left, icons on right)
  • Logo (RS_DelaDefault.svg / RS_Dela_Active.svg): 36px with 12px rounded corners, appears first in all themes. Default state uses RS_DelaDefault.svg; active state uses RS_Dela_Active.svg with gradient background (--linear-new), 12px radius.

Accessibility

Keyboard Navigation

All navigation items are keyboard accessible. Use Tab to navigate between items and Enter to activate them.

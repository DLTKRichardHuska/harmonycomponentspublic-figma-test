Command Center (variant + panel)

Command Center grid, sort and filter header affordances, and zebra rows. Sample data includes PR IDs, vendors, amounts, status as color swatches, and overdue counts. The docked panel can follow a Purchase Requisitions–style pattern (summary, overdue banner, late items). Selecting a row uses the.table-row--command-center-selected class (semi-transparent tint on cells). Pass acommand-center-aside slot with CommandCenterPanel so the panel aligns with the table (toolbar stays above the table only). In React, use the commandCenterAside prop andonRowSelect on Table with variant="commandCenter". For hierarchical rows, use grouped with data-has-children and childtr elements (data-parent-id, data-depth); limit nesting to four levels.

Usage Guidelines

Best Practices

  • Use tables only for tabular data, not for layout purposes
  • Keep column headers concise and descriptive
  • Align numerical data to the right for easy comparison
  • Use zebra striping for tables with many rows
  • Provide sorting and filtering for large data sets; use the filter bar variant with dropdowns, active filter chips, and a Clear button for narrowing by period, project, or category
  • Use reorderable tables when users need to customize row order; provide keyboard alternatives for accessibility where possible
  • Use grouped rows for hierarchical data; limit nesting to 4 levels

Accessibility

Use proper <table>, <thead>, <tbody>, <th>, and <td> elements. Include scope attributes on header cells and provide a caption or aria-label for the table's purpose.

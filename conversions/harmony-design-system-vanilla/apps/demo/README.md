# Vanilla conversion demo

Review harness for `@dltkrichardhuska/harmony-design-system-vanilla`.

**Stack (same as the package):** native ESM. Demo chrome uses Custom Elements on `HarmonyElement`. Catalog examples may be **native HTML + CSS**, **hybrid** helpers, or **`harmony-*`** tags per element strategy.

```bash
# from conversions/harmony-design-system-vanilla
npm run dev   # http://localhost:5178
```

As catalog elements sync, migrate `demo-*` chrome onto shipped Harmony surfaces (see converter playbook § Demo dogfooding).

# Spacing — Harmony Vanilla foundation

4px-grid spacing and numbered border-radius tokens.

## Consume

```css
padding: var(--space-4);
gap: var(--space-2);
border-radius: var(--radius-08);
```

Scale: `--space-0` … `--space-24` (including halves like `--space-0-5`).  
Radius: `--radius-04`, `--radius-08`, `--radius-12`, `--radius-16`, `--radius-24`, `--radius-100`.

## Don’t

- Do not invent parallel spacing scales in consumer CSS when these tokens exist.

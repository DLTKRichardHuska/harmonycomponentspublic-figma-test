Per-tab actions (open, close, ⋮)

Enable optional controls on each visible tab. Inline open and close sit beside the label; the ⋮ menu opens upward and lists actions not already inline (e.g. Set as default when open and close are both inline). Events: tab-strip:open-new-window, tab-strip:close-tab, tab-strip:set-default.

Tab 3 disables the ⋮ menu via showMenu: false while keeping the default inline actions.

With Overflow Handling

When tabs overflow, a 'More(N)' control appears. The overflow menu opens above the strip (bottom-anchored footers use the same upward pattern). Each overflow row has open-in-new-window and close actions.

Resize the container or viewport to see the overflow behavior. Tabs that don't fit will appear in the "More" dropdown.

Accessibility

Keyboard Navigation

Tabs support full keyboard navigation:

  • Tab - Navigate to tab strip
  • Arrow Left/Right - Navigate between tabs
  • Home / End - Jump to first/last tab
  • Enter or Space - Activate selected tab
  • Escape - Close overflow dropdown if open

ARIA Attributes

The TabStrip component includes proper ARIA attributes:

  • role="tablist" on the container
  • role="tab" on each tab button
  • aria-selected indicates the active tab
  • aria-disabled for disabled tabs
  • aria-controls associates tabs with their panels
  • aria-label for icon-only or overflow buttons

Screen Reader Support

Screen readers announce tab labels, active state, and navigation instructions. The active tab is clearly indicated, and disabled tabs are announced as unavailable.

Focus Management

Focus indicators are visible on all interactive elements. When a tab is activated, focus moves to the corresponding tab panel content. The overflow dropdown properly manages focus when opened.

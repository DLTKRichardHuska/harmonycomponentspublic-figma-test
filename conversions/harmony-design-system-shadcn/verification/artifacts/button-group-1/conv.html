Button Groups

synced

Button groups combine related buttons into a single visual unit.

Usage from npm

Assumes Getting Started is complete (package install, peers, provider, base styles).

import { Button, ButtonGroup } from '@dltkrichardhuska/harmony-design-system-shadcn/components';

<ButtonGroup aria-label="View period">
  <Button variant="primary">Day</Button>
  <Button variant="ghost">Week</Button>
  <Button variant="ghost">Month</Button>
</ButtonGroup>

Props

PropTypeDefaultDescription
variant'default' | 'outline''default'Segmented shell (default) or connected outline strip
size'sm' | 'md' | 'lg''md'Hint for child Button sizes (pass matching size on children)
orientation'horizontal' | 'vertical''horizontal'Layout direction of the group
childrenReactNode—Package Button children
classNamestring—Extra Tailwind / CSS classes on the root

Selection is consumer-managed via child Button variants — not a group value. Root has role="group".

Accessibility

Group label

Provide an accessible name with aria-label or aria-labelledby on the ButtonGroup root.

Keyboard Navigation

Buttons are in DOM order. Use Tab to move between them and Enter or Space to activate.

Selection

Mark the selected segment with variant="primary"; unselected segments typically use ghost.

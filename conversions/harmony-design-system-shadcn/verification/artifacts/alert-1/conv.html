Alerts

synced

Alerts display important messages that require user attention.

Usage from npm

Assumes Getting Started is complete (package install, peers, provider, base styles).

import { Alert } from '@dltkrichardhuska/harmony-design-system-shadcn/components';

<Alert variant="info" title="Information">
  This is an informational message.
</Alert>
<Alert
  appearance="enhanced"
  variant="success"
  title="Done"
  primaryAction={{ label: 'View', onClick: () => {} }}
  progressValue={60}
>
  Upload complete.
</Alert>

PropTypeDefaultDescription
variant'info' | 'success' | 'warning' | 'error''info'Severity and color
appearance'default' | 'enhanced''default'Layout — enhanced unlocks accent, actions, link, progress
titlestring—Title text (convenience API)
dismissiblebooleanfalseShow dismiss control
onDismiss() => void—Called when dismiss is activated (controlled — does not unmount)
iconstringseverity defaultOverride default severity icon (Harmony Icon name)
primaryActionAlertActionConfig—Primary action button (enhanced)
secondaryActionAlertActionConfig—Secondary action button (enhanced)
linkTextstring—Inline link text (enhanced)
linkHrefstring—Inline link href (enhanced)
progressValuenumber—Progress 0–100 — composes ProgressBar (enhanced)
childrenReactNode—Message body

Compound exports AlertTitle, AlertDescription, and AlertAction are available for custom layouts. Root has role="alert".

Accessibility

Live region

Alerts use role="alert" so assistive tech announces new messages without requiring focus.

Dismiss

Dismiss is controlled — call onDismiss and unmount (or hide) the alert in your state. The control has aria-label="Dismiss".

Actions

Prefer clear action labels. Link text should describe the destination, not "click here".

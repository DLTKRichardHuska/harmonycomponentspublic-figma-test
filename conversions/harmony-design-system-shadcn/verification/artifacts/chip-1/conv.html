Chips

synced

Chips are compact elements that represent tags, filters, or small pieces of information.

Usage from npm

Assumes Getting Started is complete (package install, peers, provider, base styles).

import { Chip } from '@dltkrichardhuska/harmony-design-system-shadcn/components';

<Chip label="Tag" />
<Chip variant="outline" icon="tag" />
<Chip removable onRemove={() => {}} label="Removable" />

Hover, focus, and pressed are CSS pseudo-states — not static props. Legacy selected is not supported.

Accessibility

Keyboard

Standard chips render as button. Use Tab to focus and Enter / Space to activate. Removable control is keyboard-activable and stops propagation from the chip click.

Dots types

horiz-dots and vert-dots are presentational spans with aria-label="More options".

Disabled

Disabled chips set disabled on the button and block remove handlers.
